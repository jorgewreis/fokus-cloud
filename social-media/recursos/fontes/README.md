# Fontes para produção de postagens

Arquivos variáveis obtidos em 13/11/2026 do repositório oficial Google Fonts:

- Montserrat: [fonte](https://github.com/google/fonts/tree/main/ofl/montserrat) e licença em montserrat/OFL.txt.
- Source Sans 3: [fonte](https://github.com/google/fonts/tree/main/ofl/sourcesans3) e licença em source-sans-3/OFL.txt; projeto original [Adobe Source Sans](https://github.com/adobe-fonts/source-sans).
- Bebas Neue existente no projeto: public/assets/fonts/google/bebas-neue-original.woff2; confirmar licença da distribuição correspondente antes de redistribuir.

As duas famílias baixadas usam SIL Open Font License; consultar os arquivos OFL completos para condições. Os arquivos foram validados como fontes TrueType e os acentos portugueses amostrados estão presentes. Montserrat oferece eixo de peso 100–900; Source Sans 3, 200–900. Não foram instaladas no sistema; o aplicativo de produção deve carregá-las ou instalá-las quando necessário.
