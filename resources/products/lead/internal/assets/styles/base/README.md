# Base CSS

Esta pasta contém a normalização e os estilos globais compartilhados.

- `_reset.css` normaliza elementos nativos sem definir identidade visual de componentes.
- `_global.css` aplica tipografia, cores, foco, estados acessíveis e utilitários globais.
- `_accessibility.css` concentra preferências de contraste, forced colors, foco e elementos nativos acessíveis.
- `_index.css` é a entrada única da pasta.

Use tokens semânticos sempre que possível. Estilos de componentes devem permanecer fora desta pasta.
