# Histórico dos documentos legais

Cada diretório identifica a versão do documento e contém o HTML preservado e um
manifesto com seu SHA-256. O conteúdo jurídico de uma versão já aceita deve ser
conservado: revisões materiais devem gerar nova versão, novos arquivos e atualização
dos formulários e da fonte de versões `App\Support\LegalDocuments`.

Os arquivos são internos ao repositório e não criam rotas públicas paralelas.
Podem ser utilizados para atender pedidos de versões anteriores, comprovar o
conteúdo do documento e comparar a versão registrada no aceite. A versão 1.0
foi preservada a partir do estado publicado no commit `124c488c`; a versão 2.0
corresponde aos documentos ampliados em 14 de outubro de 2026.

Publicar ou arquivar uma nova versão não atualiza consentimentos anteriores.
