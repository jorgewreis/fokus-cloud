Guia de uso · Base npm 2.7.0

Esta página combina a base publicada com CSS e JavaScript de composição do site. Os exemplos ilustram padrões de uso; não representam toda a API do pacote. Entenda as versões da documentação.

Componentes prontos para contexto

Peças que respondem.

Componentes são padrões de interface com aparência, estados, semântica e comportamento esperados. Este guia ajuda a escolher a peça certa sem transformar cada tela em uma decisão inédita.

Os exemplos combinam classes do Fokus Styles e estilos de composição do site para mostrar a relação entre HTML, intenção e acessibilidade. Para a referência por contrato, consulte a documentação de componentes em desenvolvimento.

01 · Ações e estados

Uma ação clara tem intenção visível.

Botões organizam a decisão principal e suas alternativas. Tamanho, contraste e estado devem continuar legíveis em teclado e touch.
