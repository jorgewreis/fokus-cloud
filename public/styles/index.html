UMA BASE, MUITAS POSSIBILIDADES

Comece pequeno.
Construa com consistência.

Instale a versão usada nesta vitrine ou consulte as versões do pacote. Os exemplos têm estilos de composição próprios, identificados no código, além dos componentes do framework.

As demonstrações usam fontes do sistema para funcionar offline. A identidade desta página usa Google Sans e Bebas Neue; essas fontes não fazem parte do ZIP.

Instalação com npm v2.7.0 
npm install fokus-styles@2.7.0

// No ponto de entrada do seu bundler:
import 'fokus-styles';

CSS do pacote + HTML semântico. As interações específicas dos exemplos são JavaScript local, sem backend.
